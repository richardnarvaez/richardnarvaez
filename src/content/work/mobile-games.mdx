## The games

Three small Android games shipped in a row, all built with Unity: **Puzzle**, **Chicken vs Cats** and **Perro Cobarde**. Short sessions, simple mechanics, and a lot learned about finishing and publishing.

## What stayed

- Shipping beats polishing: each game went to the store in weeks, not months.
- Unity's component model shaped how I still think about UI state.
- The store listing, icons and screenshots mattered as much as the gameplay.

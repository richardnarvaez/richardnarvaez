## The games

Four small Android games shipped in a row, all built with Unity: **Relax Puzzle**, **Chicken vs Cats**, **Perro Cobarde** and **The Little King**. Short sessions, simple mechanics, and a lot learned about finishing and publishing.

<Figure src="/images/apps/large/little-king-logo.webp" alt="The Little King logo" caption="The Little King" frame />

## What stayed

- Shipping beats polishing: each game went to the store in weeks, not months.
- Unity's component model shaped how I still think about UI state.
- The store listing, icons and screenshots mattered as much as the gameplay.
